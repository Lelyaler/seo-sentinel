# SEO Sentinel — AI Development Context & Standards

## Стек и окружение
- PHP 8.2+ (CLI / Apache через Docker), строгая типизация (`declare(strict_types=1);`).
- Архитектура: ООП, Пространство имен `SeoSentinel\...`, PSR-4 автозагрузка.
- Нулевые внешние зависимости: использование встроенных высокопроизводительных расширений PHP (`dom`, `libxml`, `curl`, `json`, `mbstring`).

## Стандарты кода
1. **Типизация**: Каждый метод и функция обязаны иметь явные типы аргументов и возвращаемых значений.
2. **Безопасность**:
   - Валидация всех входящих URL (`filter_var($url, FILTER_VALIDATE_URL)`).
   - Защита от SSRF (проверка приватных IP-диапазонов).
   - Экранирование вывода в HTML (`htmlspecialchars(..., ENT_QUOTES, 'UTF-8')`).
3. **Обработка ошибок**: Использование пользовательских исключений `SeoSentinelException` и аккуратная обработка сетевых сбоев.

## Запуск и тестирование
- Веб-сервер: запуск встроенного сервера PHP на порту 8000.
- CLI-команда: `php bin/seo-sentinel <action>`.
- Проверка синтаксиса: `php -l <file>`.
