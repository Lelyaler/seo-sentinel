# Регламент оценки GEO (Generative Engine Optimization)

Критерии оценки готовности страницы к цитированию в AI-поиске:
1. **Прямые ответы (Direct Answers / Definition blocks)**:
   - Наличие сжатого определения (до 40-50 слов) сразу под ключевым заголовком H2.
2. **Q&A форматирование**:
   - Вопросы пользователей в заголовках (`Как выбрать...`, `Сколько стоит...`, `В чем разница между...`).
3. **Фактическая плотность (Fact Density)**:
   - Конкретные цифры, проценты, таблицы характеристик, списки преимуществ вместо «воды».
4. **E-E-A-T сигналы (Опыт, Экспертность, Авторитетность)**:
   - Указание автора, эксперта, ссылок на первоисточники, даты актуализации.
5. **Таблицы и маркированные списки**:
   - AI-модели в 3 раза чаще цитируют данные, оформленные в теги `<table>` или `<ul>/<ol>`.
