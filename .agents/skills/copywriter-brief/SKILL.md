# Регламент генерации ТЗ копирайтеру

При формировании технического задания для копирайтера или AI-модели:
1. **Параметры объема**:
   - Четко указывать дефицит объема (разница между текущим текстом и бенчмарком выдачи).
2. **Структура заголовков (Outline)**:
   - Включать обязательные H2-разделы, выявленные анализом Content Gap (FAQ, Цены, Этапы, Гарантии).
3. **Семантика и LSI**:
   - Предоставлять список второстепенных ключевых фраз (LSI) с инструкцией естественного вхождения.
4. **Готовый AI-промпт**:
   - Генерировать системный промпт для ChatGPT/Claude с ролью «Senior SEO Copywriter», контекстом ниши и правилами E-E-A-T (без «воды», с фактами и маркированными списками).
