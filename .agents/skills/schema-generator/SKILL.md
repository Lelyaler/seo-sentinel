# Регламент генерации Schema.org JSON-LD

При формировании микроразметки:
1. Использовать строго формат `<script type="application/ld+json">`.
2. Контекст всегда `"@context": "https://schema.org"`.
3. Типы разметки:
   - **FAQPage**: для страниц с блоком вопросов и ответов (структура `mainEntity: [Question, acceptedAnswer]`).
   - **Service**: для коммерческих страниц услуг (название, провайдер, описание, оферта).
   - **Article / BlogPosting**: для информационных статей и блогов (заголовок, автор, дата публикации).
   - **Organization**: для страниц компании (название, логотип, контакты, соцсети).
   - **BreadcrumbList**: навигационная цепочка («хлебные крошки»).
4. Валидация: разметка не должна содержать неэкранированных кавычек, переносов строк внутри JSON-строк и должна соответствовать требованиям Google Rich Results.
